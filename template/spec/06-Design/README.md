# 06 · Design

The visual and interaction design, written by the **design-lead** in the Design
phase (`/design`), between Define and Architect.

- `DESIGN-BRIEF.md` - the art direction: the thesis, palette, type, layout, motion
- `DESIGN-SYSTEM.md` - the tokens and component inventory the frontend implements
- `mockups/*.html` - real, self-contained screen mockups covering every state

*Empty until `/design` runs. It designs the screens the PRD names, so `/define`
comes first.*
