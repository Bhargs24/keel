# 50 · Audits

Dated **SNAPSHOT** documents, never edited after their date. The feasibility
verdict (`/feasibility`), readiness stress tests, and decision records live here.

If an audit turns out wrong, it is re-run as a new dated audit - never quietly
corrected. An audit that gets edited after the fact is not a record of anything.
